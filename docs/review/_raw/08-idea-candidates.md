ranks these; anything without a real table/module to hang off gets killed.

   `music_play_log` + `game_session` + `quiz_session` are all dated event logs; nothing renders a
   cross-source calendar. Reuses `CalendarHeatmap`.
2. Per-year time breakdown on StatsPage (`mediaRepo.timeStats` currently returns one all-time total).
3. "Dropped but 80% done" shelf — `progress / total_units` vs status, a one-query MediaListPage filter.

   already records each wrap via `payload.prior`.
5. Relations-driven "what's next in this franchise" — `media_relation` exists and is imported but
   only rendered as a flat list.
6. Import-queue: paste N AniList/TMDB URLs, import in sequence behind `withActivity`.

   in-progress with no `checklist_log` row for 30+ days ("stalled").
