# Approved theme artwork

Each theme has three styles (2026-09-26 study, `previews/theme-study-2/`): Lain — Present day, Copland OS,
Red shadows; Metal Gear — Codec, Dossier, Shadow Moses; Miku — Crypton teal, Open sky, Concert night;
Twin Peaks — Waiting room, Douglas firs, Black Lodge. Crypton teal uses #39C5BB, the swatch Crypton shows
beside "Blue-Green" on its official character page.

Local assets selected in the September 2026 theme study. The user selected option three
for **Lain — Wired, after dark** and **Metal Gear — Solid / Ink**. They also approved
option two for **Hatsune Miku — Beyond the blue** (blue-filled revision) and
**Twin Peaks — The waiting room** (warm curtain-red revision).
No artwork was generated. These files are bundled for offline use; runtime never fetches them.
The existing Lain avatar and desktop application icon are unchanged.

Barlow Condensed (500/600/700) and Chakra Petch (500/600) are bundled Google Fonts.
League Gothic (variable width, Metal Gear / Dossier) and Oswald (variable 200–700, the Twin Peaks / Douglas firs title
lettering) come from the official Google Fonts repository with their OFL files in `fonts/`. Both are free
approximations: the MGS2 logo uses commercial Helvetica Ultra Compressed and the 1990 titles a discontinued
condensed Avant Garde Gothic.
Quicksand (variable 300–700) and Bodoni Moda (variable 400–900) come from the
official Google Fonts repository and carry their own OFL files in `fonts/`.
Their embedded copyright notices and SIL Open Font License 1.1 are retained under `fonts/`.
IBM Plex Mono and VT323 continue to come from the existing `@fontsource` dependencies.

Artwork belongs to its respective creators/rightsholders. The repository's code license does
not license these third-party images. The selected local theme study is in gitignored
`previews/theme-study/`; it is not a runtime dependency.

Miku’s approved panel blue is #22B9CE, sampled from the [official costume sheet](https://piapro.net/intl/images/official_cos_miku.jpg), with a lighter #6FD4E2 canvas. Twin Peaks uses #9B2018 chrome informed by the FWWM curtain photograph, not the earlier wine-purple palette. These are reference-led adaptations, not claims of universal official hex specifications. The final local approvals are in `previews/miku-blue-study/` and `previews/miku-peaks-color-study/`; neither is a runtime dependency.
