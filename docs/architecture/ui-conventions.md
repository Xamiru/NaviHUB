## Shared UI primitives

Shared UI primitives (2026-07-04, extended 2026-07-06) — reuse before writing new ones: `Section` (uppercase-headed section, `subtitle`/`className` props), `StatTile`, `PageStatus` (page-level loading/not-found), `BackButton` (history-back — ALL detail/form sub-pages use it; fixed-parent `← Japanese`-style breadcrumb Links are the deliberate exception), `SortableList`/`SortableRow`/`useOptimisticReorder` (drag-reorder w/ rollback — playlists + lists; NOT the play queue, which is client-only and can hold duplicate ids → plain ▲▼× buttons), `MusicEntityHeader` (album/artist hero), `playTracks()` in `lib/musicTracks.ts` (every music Play/Shuffle button), `BarChart` (single-series divs chart), `CalendarHeatmap` (GitHub-style year grid), `QuizRecord` (personal best + recent rounds block), `MediaCard` (now `components/MediaCard.tsx` — one card app-wide, `showTypeBadge` for cross-type strips, `showProgressBar` for Continue; MediaListPage re-exports it). **UI consolidation (2026-07-28):** `Tabs` (THE tab idiom — underline horizontal, inset-bar vertical, per-tab `to` renders a Link, `actions` right-slot; replaced four competing tab looks), `PageHeader` (title/subtitle/actions; `back="history"` renders BackButton, `back={{to,label}}` renders the quiet breadcrumb — encodes the back convention), `ActionMenu` (text "More" trigger + popover; where Delete and rare actions live — never beside Edit), `DoorCard` (accent-gradient link card, HomePage rail), `EmptyState` (the ONE filled button goes in its `action`), `Pager` (Prev/Next — text labels, no arrows), `StatInline` (compact stat for dense rows — MediaDetail header; StatTile stays for dashboards). **Polish pass (2026-08-01):** `HubCard` (quiet section-hub card — plain card, hover accent border, `to`/`onClick` variants; the hub grids on Japanese/Quiz/Programming homes. DoorCard's glow stays reserved for Home's right rail; GachaHomePage's GameCard is the deliberate exception — it carries the user's per-game hero art), `PillGroup` (`Group`+`Pill` — the labelled single-select pill row on every quiz/tournament setup screen), PageHeader gained `eyebrow` (chip row above the title), `.kbd` (styles.css — THE keyboard-hint chip; quiz options, shortcut lines, Topbar). PageHeader/PageStatus/EmptyState/Section are now adopted app-wide — new pages start from them, never a bare `<h1>`/`Loading…` `<p>`. Loading convention: page-level → `PageStatus`; in-section → `<p className="text-sm text-gray-500">Loading…</p>`. One `btn-primary` per screen is enforced; when an `EmptyState` shows, any header button with the same verb is conditionally hidden (its `action` holds the one filled button). Forms convention: `PageHeader back="history"`, labels are `<label className="label">` (never `<div className="label mb-1">` — double margin), full-width bottom `btn-primary` Save, NO Cancel button (Back/Esc is cancel). **NO emoji and NO decorative glyphs anywhere — user directive 2026-07-12, hardened 2026-08-01 (strict purge: button-label prefixes, title glyphs, watermarks, the palette icon column are all gone; `MediaConfig.icon` is no longer rendered anywhere).** Functional glyphs stay: reader HUDs, `✕` close (always with `aria-label`), ✓/○ state marks, ★ score/rarity data badges, ♥ like toggles, `←` in back links, ▸/▾/› disclosure. **Player transport is SVG, never unicode (2026-08-06):** `components/PlayerIcons.tsx` (Play/Pause/Prev/Next, currentColor, 1em) — ⏮/⏭ are emoji-presentation-default codepoints that Windows renders as blue Segoe UI Emoji pictures, and `❚❚` never aligns; every transport button (NowPlayingBar, NowPlayingPage, VideoControls, QueuePanel, ThemeRow/ThemeSongsPage play buttons, reader chapter-skip buttons) uses these components.

## Theme — the Lain Wired terminal

**Theme (2026-07):** the UI is the Serial Experiments Lain "Wired terminal" — the app's ONLY theme (a switchable normal theme existed briefly on 2026-07-12; the user liked lain and had it removed, incl. `lib/theme.ts`). ALL palette colors + the radius scale are CSS variables in the styles.css `:root` block, surfaced as Tailwind tokens via `rgb(var(--x) / <alpha-value>)` in tailwind.config.js (`base.*`, `accent*`, full `gray` ladder, `white`; `borderRadius` DEFAULT/sm..2xl — `full` deliberately unmapped for pills/avatars/spinner). Never hardcode those hexes in renderer code — change/add vars in `:root`. Content/data colors stay literal on purpose: StatsPage `TYPE_COLORS`, `shared/gacha.ts` game colors, `MusicPlaceholder`, stock `red/green/amber/yellow/sky/purple/black`. The "WIRED CHROME" section at the bottom of styles.css holds: the mono-chrome selector list (headings/buttons/inputs/aside/header/.uppercase → `--font-mono`; body text stays Inter), the CRT overlay (`body::before/::after` z 80/81, above the z-50 UI, disabled on reader routes via the `data-reader` attribute App.tsx stamps), brand glitch (`.lain-crt`/`.brand-glitch` on the Sidebar brand), glows, and the inverse-video override — white-on-phosphor-green is unreadable (1.7:1), so `.btn-primary, .bg-accent.text-white { color: base-900 }`; keep writing `bg-accent text-white` in markup. Any new animation must sit inside `@media (prefers-reduced-motion: no-preference)`. Boot splash `BootSequence` (mounted in main.tsx) runs once per app launch via a module-scope sessionStorage guard (`ui.booted`) — module scope is what makes it StrictMode-safe; don't move it into an effect. Chrome fonts are bundled `@fontsource` packages: IBM Plex Mono (UI) + VT323 (brand/boot only — single weight, no `…` glyph, no JP) — self-origin because CSP has no remote `font-src`. BrowserWindow `backgroundColor` mirrors `--base-900` (`#0a0f0b`) — keep them in sync. **App icon** (`assets/icon.png`, 512², also the user's .desktop shortcut + electron-builder win/linux icon) is a phosphor-duotone Lain portrait; the same 512² art is `src/renderer/src/assets/lain.png`, reused by the sidebar brand avatar AND the HomePage hero mark (the old inline hub-SVG Logo is gone; renderer asset imports need `src/renderer/src/env.d.ts` `/// <reference types="vite/client" />`). The user's desktop launchers use the themed icon name `navihub` (`~/.local/share/icons/hicolor/512x512/apps/navihub.png`) — after changing `assets/icon.png`, re-copy it there too. Sidebar idiom: TEXT-ONLY nav links (no glyphs), `SectionLabel` ("// LABEL ───" terminal-comment headers), active link = `bg-accent/10 text-accent` + inset 2px phosphor bar (`shadow-[inset_2px_0_0_0_rgb(var(--accent))]`, no layout shift), decorative `wired-dot` "Connected to the Wired" footer. `NavGroup` is the one disclosure shell (media types via `MediaSection`, plus Music [Liked/Listening stats], Gacha [per-game], Japanese [Roadmap/Review/Dictionary/Drills/Guide], Programming [Cheatsheets/CLI practice]); labels are LIBRARY/PLAY/LEARN only (CURATE dissolved 2026-08-01) — never a label wrapping a single bare link. Structure: top cluster Home/Checklist/Stats, LIBRARY = media + Music + Lists + Tags, PLAY = Quiz + Gacha, LEARN = Japanese/English/Programming, footer = Torrents + Settings. The catch-all route redirects to `/` (Home).

## Menu bar and UI zoom

**Menu bar + UI zoom (2026-08-06):** the native File/Edit/View bar is HIDDEN by default (`ui.menuBar` setting, '1' = shown; Settings → General card, live via `app:setMenuBarVisible`). The default menu STAYS the application menu so its accelerators (Ctrl+R, F11, Ctrl+Shift+I, Ctrl+= / Ctrl+-) work while hidden. Ctrl+wheel zoom is the app's own: a global wheel listener in App.tsx (skipped on reader routes — the manga reader owns Ctrl+wheel for page zoom — and when `defaultPrevented`) calls `app:bumpUiScale`, which steps the SAME persisted `ui.scale` the Settings pills write (main applies + persists, so the controls can't drift). Both `getAllWindows` loops (zoom, menu bar) skip the pop-out player widget (`src/main/widget.ts`) — its 320×64 pill is fixed-size and menu-less by design.
